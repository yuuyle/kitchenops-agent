- 検出履歴では `Azure AI Vision` の caption/tags と `Azure OpenAI` の正規化結果が表示される場面を必ず映す。
- ナレーションでは「固定カメラの観測 -> Azure AI Vision の画像理解 -> Azure OpenAI による食材正規化 -> 在庫DB更新」というエージェントの判断ループを説明する。

目的: 機能説明だけでなく、「現場の食材オペレーションをAIエージェントが回す」ストーリーとして見せる。

## 0:00-0:20 課題提示

画面:
- タイトル: KitchenOps Agent
- 食材在庫、期限、献立、買い足しのキーワード

ナレーション:

## 0:20-0:40 解決策

画面:
- Azure公開URLを開く
- カメラタブを表示
- Microsoft AI パネルを映す

ナレーション:
> KitchenOps Agent は、固定カメラで食材の入庫と使用を観測し、在庫DBを更新し、1週間の献立と買い足しリストまで提案するAIエージェントです。アプリは Azure App Service 上で動作し、Azure AI Vision と Azure OpenAI へ拡張できる接続境界を持っています。

## 0:40-1:20 入庫デモ

### 実AIで撮るときの操作

ここはサンプルの「デモ入力」ボタンではなく、カメラ映像からの判定を使う。

1. 公開URL `https://kitchenops-agent-yuuya-20260601.azurewebsites.net` を開く
2. 左メニューで「カメラ」を開く
3. Microsoft AI 連携が `Azure AI` または Azure OpenAI / Azure AI Vision configured になっていることを映す
4. 「登録」モードを選ぶ
5. 「開始」を押してブラウザのカメラ許可を承認する
6. 「自動スキャン」は録画では一度OFFにして、判定タイミングを手動にすると撮りやすい
7. カメラの枠内に食材を2〜3秒止めて見せる
8. 「判定」ボタンを押す
9. 検出履歴で `Azure AI Vision:` と `Azure OpenAI:` が出ていることを映す
10. 在庫タブで数量が追加または増加したことを映す

撮影に使いやすい食材は、バナナ、トマト、じゃがいも、キャベツ、牛乳。現状のAI正規化カタログにあるため、判定結果が安定しやすい。パッケージ食品や複数食材を同時に映すと、判定が近い候補へ寄ることがあるので、デモ動画では1種類ずつ映す。

「デモ入力」ボタンは審査員がカメラなしで流れを確認するためのフォールバックで、AI実演としては使わない。

操作:
1. カメラタブで「登録」モードを表示
2. 「開始」でカメラを起動する
3. 食材を1種類だけカメラ枠内に入れ、2〜3秒止める
4. 「判定」を押す
5. 検出履歴で `Azure AI Vision:` と `Azure OpenAI:` の行を見せる
6. トラッキング、在庫数の変化を見せる
7. 可能なら確認キューも見せる

ナレーション:
> 食材は、写真撮影ボタンを押すのではなく、カメラ前を通過するものとして扱います。Azure AI Vision が画像から caption、tags、objects を抽出し、その結果を Azure OpenAI が在庫カタログの食材名へ正規化します。同じ食材が連続して映った場合は、トラッキングIDで集約します。

## 1:20-1:45 在庫と補正

操作:
1. 在庫タブを開く
2. 冷蔵 / 冷凍 / 常温フィルタを切り替える
3. 残量入力欄を少し見せる

ナレーション:
> 認識結果は在庫として保存されます。現場ではAIの認識が常に完璧とは限らないため、残量入力や手動補正を用意しています。100%自動化よりも、運用が止まらず補正できることを重視しました。

## 1:45-2:20 献立生成

操作:
1. 右上の「献立生成」を押す
2. 献立タブで1週間分を見る
3. 買い足しリストを映す
4. レシピタブへ移動してレシピ詳細を見る

ナレーション:
> 在庫が揃ったら、家族構成、好み、栄養目標、調理時間、予算を考慮して1週間の献立を生成します。在庫でまかなえる割合と、足りない食材の買い足しリストも作成します。レシピ詳細では材料、手順、栄養目安、検索元を確認できます。

## 2:20-2:45 使用デモ

操作:
1. カメラタブへ戻る
2. 「使用」モードに切り替える
3. 登録済みの食材と同じものをカメラ枠内に入れ、2〜3秒止める
4. 「判定」を押す
5. 検出履歴で `Azure AI Vision:` と `Azure OpenAI:` の行を見せる
6. 在庫タブで数量が減ったことを見せる

ナレーション:
> 調理時は使用モードに切り替え、使った食材を同じカメラで検出します。在庫から数量を差し引き、使い切った場合は削除します。使った後の残量も、在庫画面から補正できます。
